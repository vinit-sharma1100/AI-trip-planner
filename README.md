# 🌍 TripSphere

TripSphere is an AI-powered travel planner that generates personalized trips based on user preferences like budget, number of travelers, and duration.

## 🚀 Features

- Google Authentication  
- AI Trip Generation (Gemini AI)  
- Budget & Traveler-based Planning  
- Day-wise Itinerary  
- Hotel & Place Suggestions  
- Google Maps Navigation  
- Save Trips
